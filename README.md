# CBC KPI — נציג שטח

שלושה כרטיסי KPI ב‑RTL בעיצוב SAP Horizon, רקע לבן. כל קובץ עצמאי — נפתח ישירות בדפדפן.

| קובץ | גודל | תוכן |
| --- | --- | --- |
| `InsightsKPI.html` | 500×300 | תובנות: קצב מכירות, הפסד מכירות פוטנציאלי, לקוחות באיחור (לחיצה → Account List), מוקד טלפוני (@Neta) |
| `SalesForecastKPI.html` | 500×300 | מד מכר מול תחזית + % עמידה + פער + קצב נדרש ליום; אייקון דריל / דאבל‑קליק פותח פירוט לפי נקודות מכירה |
| `VisitKPI.html` | 513×300 | ביקורים מתוכננים / שבוצעו / שנותרו החודש (124/97/27), פס התקדמות 78%, לקוחות שלא ביקרת מעל 14 יום (דאבל‑קליק → Account List); אייקון דריל → Visit List |

## ניווט

הדריל ב‑VisitKPI וב‑InsightsKPI שולח `postMessage` לחלון האב:

```js
{ operation: "navigation", params: { routingKey: "visit" | "account", viewType: "list" } }
```

הניווט פועל רק כשהכרטיס מוטמע בדף שמאזין להודעה.

כל הערכים הם נתוני הדגמה.
